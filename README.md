# Passworder

Локальный менеджер паролей на Java 21. Без регистрации и сервера.

Что уже есть:

- Логин, пароль, ссылка и название сервиса.
- Добавление, редактирование, удаление, поиск и избранное.
- Копирование логина и пароля. Очистка собственного буфера через 20 секунд.
- Светлая и темная темы, генератор паролей.
- Переключатель солнце/луна в верхней части окна, плавные нажатия и прокрутка.
- Поиск, выбранная запись и прокрутка сохраняются при смене темы.
- Мастер-пароль, автоблокировка, зашифрованные резервные копии.
- Трей и глобальная горячая клавиша для Windows.

## Запуск

В IntelliJ открой `pom.xml` как Maven-проект, выбери JDK 21 и запусти
`svarcovv.dev.passworder.Passworder`.

Или из терминала:

```powershell
.\mvnw.cmd verify
java -jar target\Passworder.jar
```

При первом запуске придумай мастер-пароль минимум из 12 символов.
Он не сохраняется. Сбросить его или восстановить без него данные нельзя.

Сборка Windows-программы со своей Java внутри:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\package-windows.ps1 -Destination dist\0.2.0
```

Запускай `dist\0.2.0\Passworder\Passworder.exe`. Переносить нужно всю папку `Passworder`.
Отдельно устанавливать Java для этой сборки не нужно.
`run.cmd` запускает готовую сборку или JAR.
Для повторной сборки укажи новый каталог через `-Destination dist\build-2`.

## Управление

| Клавиши | Действие |
| --- | --- |
| Ctrl+Alt+P | Показать окно поверх других окон |
| Ctrl+N | Добавить запись |
| Ctrl+F | Поиск |
| Ctrl+Shift+L | Заблокировать |
| Ctrl+C в таблице | Копировать пароль выбранной записи |
| Ctrl+Shift+C в таблице | Копировать логин |
| Enter / Delete в таблице | Редактировать / удалить |
| Shift+F10 в таблице | Меню записи |

Программа должна быть запущена для глобальной горячей клавиши. Крестик прячет
ее в трей и блокирует хранилище. Сворачивание тоже блокирует. Для полного выхода
выбери «Выход» в меню значка в трее. Сочетание клавиш и время блокировки меняются
в настройках. Повторный запуск показывает уже открытый экземпляр.
Анимации можно отключить в настройках. Смена темы не сбрасывает параметры генератора.

## Где данные

`%LOCALAPPDATA%\Passworder\vault.pwr` - зашифрованное хранилище.
`vault.pwr.bak` - зашифрованное состояние перед последним сохранением.
Настройки темы и горячих клавиш лежат рядом, без данных записей.

Копию можно сохранить в настройках. Чтобы восстановить ее, заблокируй хранилище,
введи мастер-пароль этой копии и нажми «Восстановить из копии».
Сначала программа проверит копию, затем заменит текущее хранилище.

Сборка скачивает зависимости Maven. Приложение не выполняет сетевых запросов.
Сайт открывается в браузере только по нажатию на ссылку.
Данные из профиля Windows не входят в исходники, сборку или Git.

## Проверки

`mvnw.cmd verify` проверяет шифрование, повреждение файлов, резервные копии,
отказ записи, генератор и допустимые ссылки. `DesktopSmoke` - ручной тест окна
на вымышленных данных в отдельном временном хранилище. Он также проверяет темы,
редактирование, копирование, трей и глобальную клавишу. Не запускается в CI.
